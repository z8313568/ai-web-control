# 安全模型

## 设计立场

按用户明确需求，本系统采用「**完整 Shell + 全量审计**」策略：
**不阻断**任何命令（包括危险命令），但所有操作有日志、有告警、有一键总开关。

这是一把锋利的刀——能力大，风险也大。请务必读完本文。

## 信任边界

```
┌──────────────────────────────────────────────────────────┐
│  AI 网页（DeepSeek）—— 半信任                            │
│  AI 的输出会被解析成可执行命令，AI 可能被诱导或出错。     │
│  这是最大的风险面。                                       │
└──────────────────────────────────────────────────────────┘
                        ↓ webctl 协议块
┌──────────────────────────────────────────────────────────┐
│  Chrome 扩展 —— 可信                                     │
│  你加载的代码，做速率限制、开关、结果展示。               │
└──────────────────────────────────────────────────────────┘
                        ↓ Native Messaging（仅本机，4字节帧）
┌──────────────────────────────────────────────────────────┐
│  本地 host (Python) —— 高权限                            │
│  以你的用户身份执行任意 shell。权限等于你登录后开终端。   │
└──────────────────────────────────────────────────────────┘
```

## 防护措施（已实现）

| 措施 | 位置 | 说明 |
|---|---|---|
| 一键总开关 | sidepanel / storage | 关闭后所有 exec 请求被拒，跨 SW 重启持久化 |
| 速率限制 | background.js | 单来源每秒最多 5 条请求，防止 AI 失控刷命令 |
| 危险关键字告警 | executor.py | 命中 `rm -rf /`、`mkfs`、`dd if=`、`shutdown` 等模式，结果标 `dangerous:true`，UI 变橙色 |
| 全量审计 | audit.py | 每次 action（含参数、dangerous 标记、时间戳、pid）落盘 JSONL |
| 协议校验 | protocol.js | 非法 action / 损坏 JSON 不执行，作为错误反馈 |
| allowed_origins | native manifest | 仅指定 extensionId 的扩展能连 host，防止其他扩展接管 |

## 已知风险（如实告知）

1. **AI 可被提示词注入**。如果 AI 读到恶意网页内容，可能在回复里塞入 webctl 块，
   触发命令执行。缓解：dangerous 关键字告警 + 总开关 + 审计。
2. **完整 Shell 无沙箱**。host 进程能做你能做的一切：删文件、改配置、装软件。
   这不是漏洞，是设计——但意味着你不能在不可信的 AI 对话里使用本系统。
3. **DeepSeek DOM 变动**。`ds-markdown` 类名若改版，监听失效（不影响已执行的功能，
   只是新的 AI 输出不再被捕获）。需要维护适配器。
4. **MV3 生命周期**。offscreen document 是当前最稳的长连接方案，但 Chrome 未来版本
   可能调整保活策略。

## 建议的使用姿势

- **只在信任的对话里启用**。遇到可疑 AI 输出，立刻用侧边栏总开关关闭。
- **定期看审计日志**。`audit-YYYYMMDD.jsonl` 里 `dangerous:true` 的条目重点复查。
- **内网隔离**。本系统不主动连外网，但 host 执行的 shell 命令可能联网（如 curl）。
  若要严格隔离，在系统防火墙层面限制。
- **不要在生产服务器上装**。本系统面向个人电脑/开发机。

## 不在本系统防护范围内的事

- host 执行的命令本身的副作用（那是命令自己的事）
- DeepSeek 账号安全（那是 DeepSeek 的事）
- 浏览器其他扩展的隔离（Chrome 自己的扩展沙箱负责）
